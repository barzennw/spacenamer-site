Which Macs and which macOS.

Hardware

Apple silicon — supported

Every Mac with an M-series chip. SpaceNamer is built natively for Apple silicon.

Intel Macs — not supported

There is no Intel build, and Rosetta does not help: the app ships as an Apple silicon binary only.

What it needs from macOS

  • No Accessibility permission. Nothing to approve in System Settings → Privacy & Security.
  • No Screen Recording permission. SpaceNamer never reads the contents of your screen.
  • No System Integrity Protection changes. Nothing is injected into macOS, so it is fine on a managed work Mac.
  • No network access for day-to-day use. The only request it ever makes is the license check.

How each macOS release is tested

When Apple ships a new version of macOS, SpaceNamer is tested on it that week and this page is updated with the result. Each test covers the things most likely to break:

  • Detecting every desktop, on one display and on several.
  • Naming a desktop and seeing that name in the menu bar.
  • Switching to each desktop by clicking its name.
  • Names surviving a restart and surviving Mission Control reordering.

If a macOS update breaks something, tell us — a report on the day of a release is worth a great deal. Write to [support email] with your macOS version and what you saw. Fixes for macOS compatibility are free, like every other update.

Beta versions of macOS

SpaceNamer is tested against public betas where possible, but a beta can change behaviour after that test. If you run beta macOS, expect the occasional surprise and please report it.
