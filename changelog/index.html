Changelog

What changed, and when.

Every update is free — there is no version 2 to buy. Newest first.

1.0.5 28 October 2026 Current
  • Rows no longer move while the Rename window is open. macOS reorders its list of fullscreen desktops as you use them, which could shift a row under your pointer and rename the wrong desktop. Positions are now fixed for as long as the window is open, and a desktop created meanwhile is added at the bottom.
1.0.4 28 October 2026
  • Typing a name no longer disturbs the other rows. Each desktop keeps its own text while you edit, so a name can no longer land on the wrong desktop or jump back as you type.
  • Names for desktops that no longer exist are forgotten. Closing a fullscreen window destroys its desktop for good, and those names used to pile up invisibly.
  • Rows always appear in Mission Control order: numbered desktops first, then fullscreen apps.
1.0.3 27 October 2026
  • New emoji picker. Choosing an emoji is now a small grid inside SpaceNamer rather than the system Character Viewer, which would not reliably reopen after you closed it without choosing anything.
  • Every desktop is clickable straight away. A desktop you had just created used to stay greyed out until you had visited it once.
  • Emoji made of several parts — flags, skin tones, family sequences — are kept whole.
1.0.1 27 October 2026
  • Choosing an emoji is much less fiddly. The picker no longer opens when you simply tab between fields, the text no longer shifts under you while you type, and picking a new emoji now replaces the old one instead of being ignored.
  • Emoji made of several parts — flags, skin tones, family sequences — are kept whole.
  • Only emoji are accepted, so a stray keystroke can no longer become a desktop's icon.
  • Emoji are shown larger, and are actually legible at a glance.
1.0 26 October 2026
  • First public release.
  • Name every Mission Control desktop and see the current one in your menu bar.
  • Click a name to switch to that desktop — no Accessibility permission needed.
  • Fullscreen apps appear by name alongside your desktops.
  • One list per display on multi-monitor setups.
  • Updates install themselves from here on.

How updates reach you

Updates are free for the life of the app and install from within SpaceNamer. Fixes for new macOS releases are part of that — see the compatibility page for what is tested.
